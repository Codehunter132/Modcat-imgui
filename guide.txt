=====================================================
    MODCAT AUTHENTICATION SERVER - HOSTING GUIDE
=====================================================

To make your Mod Menu's login system work for players all over the world, you need to host the `server` folder on the internet so it runs 24/7. 

Here are the 2 best and easiest FREE platforms to host your Node.js backend:

-----------------------------------------------------
OPTION 1: REPLIT.COM (Easiest & Fastest for Testing)
-----------------------------------------------------
Replit is a free online coding platform. It's the absolute easiest way to host this without any setup.

1. Go to https://replit.com and create a free account.
2. Click "Create Repl" and choose "Node.js" as the template.
3. Once the workspace opens, delete the default files it gives you.
4. Drag and drop all the files from your local `server` folder (`server.js`, `package.json`, and the `public` folder) directly into the Replit file explorer on the left.
5. Click the big green "Run" button at the top.
6. Replit will automatically install the packages (express, sqlite3, cors) and start the server.
7. Above the web preview window, you will see a URL (e.g., `https://your-repl-name.yourusername.repl.co`). This is your Server URL!
8. Open your Android Project -> `app/src/main/java/com/Cat/mod/GLES3JNIView.java` and change the IP address to your new Replit URL:
   Example: URL url = new URL("https://your-repl-name.yourusername.repl.co/api/verify?key=" + key);

NOTE: Free Replit servers "sleep" if nobody uses them for a few minutes. The first login might take 5-10 seconds as the server wakes up.

-----------------------------------------------------
OPTION 2: RENDER.COM (More Professional / Production)
-----------------------------------------------------
Render is a professional hosting service that offers a free tier. It is much better if you want a reliable server.

PREREQUISITE: You need a GitHub account.

1. Go to https://github.com and create a new private repository (e.g., "Modcat-Server").
2. Upload the contents of your `server` folder (`server.js`, `package.json`, and `public/`) to this GitHub repository.
3. Go to https://render.com and sign up using your GitHub account.
4. Click "New" -> "Web Service".
5. Select your "Modcat-Server" repository from GitHub.
6. Fill in the details:
   - Name: modcat-auth
   - Environment: Node
   - Build Command: npm install
   - Start Command: node server.js
   - Instance Type: Free
7. Click "Create Web Service".
8. Render will now build and deploy your server. This takes about 2-3 minutes.
9. Once live, Render will give you a URL (e.g., `https://modcat-auth.onrender.com`).
10. Update your Android Java code (`GLES3JNIView.java`) with this new URL just like in Option 1!

*IMPORTANT NOTE FOR RENDER FREE TIER*: Render's free tier does not have "Persistent Disk" storage. This means every time the server restarts (which it does automatically occasionally), your `keys.db` SQLite database will be wiped and all keys will be deleted. If you plan to sell keys or have hundreds of users, you will eventually need to upgrade to a paid tier ($7/mo) to keep the database permanently saved, or change the backend to use a free MongoDB database instead of SQLite.

-----------------------------------------------------
HOW TO ACCESS YOUR ADMIN PANEL
-----------------------------------------------------
No matter which host you choose, you can access your Key Generator UI by simply going to your server URL in any web browser.

Example: `https://your-server-url.com/`

- Password: admin123
- From there, you can generate as many keys as you want!
